# Portfólio de Filipe Santana

Portfólio pessoal de Filipe Santana, desenvolvedor front-end e back-end, CEO da Nivano Studio e criador do NiveFinances. O site apresenta um resumo profissional, projetos e links para contato e redes sociais.

## Acessar o site

Abra o arquivo `index.html` no navegador. Para executar localmente com um servidor HTTP, abra o terminal nesta pasta e rode:

```bash
python -m http.server 8000
```

Depois, acesse [http://localhost:8000](http://localhost:8000).

## Páginas

- `index.html`: página inicial e links sociais.
- `sobre/sobre.html`: apresentação profissional.
- `projects/projects.html`: projetos desenvolvidos e em andamento.

## Projetos em destaque

- NiveFinances — sistema de gestão financeira pessoal, empresarial e universitária.
- Pizzaria Dona Rosa — site e dashboard.
- Haja Luz.
- Espaço Açaí.
- Portfólio IEPOP, Portfólio Nivano e Prospector Nivano — itens identificados no site como em desenvolvimento.

## Tecnologias e recursos

- HTML5 e CSS3.
- Vídeo WebM usado como fundo das páginas (`asset/purple-swirls.webm`).
- Imagens, ícones e fontes locais organizados nas pastas `asset/`, `projects/asset/` e `fonts/`.
